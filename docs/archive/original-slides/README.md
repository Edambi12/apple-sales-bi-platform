# Original planning slides (archive)

These four images come from the first, French-language presentation of the
project. They are kept as a record of how the work started and are **not** part
of the current documentation.

| File | Content |
| --- | --- |
| `business-understanding.jpg` | Initial business context slide |
| `data-understanding.jpg` | First description of the five tables |
| `kpi-list.jpg` | Initial KPI wish list |
| `equivalence-tree.jpg` | Objective tree linking goals to KPIs |

Points superseded by the current documentation:

- The context slide quotes general facts about Apple Inc. that do not come from
  the dataset (the dataset has 75 stores in 19 countries).
- The KPI list and objective tree include indicators the dataset cannot support:
  sales per square foot, category margin, average basket value and average
  resolution time. See [KPI definitions](../../kpi-definitions.md).
- The slides use the Apple logo. It is not used anywhere in the current
  application or documentation.
